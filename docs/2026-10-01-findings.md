# Beta V2.1 findings — 2026-10-01

## Findings addressed

- Admin was still a report-detail panel without a clear work queue. Added a dedicated two-column Admin workspace with status filters, case search, concise case rows, and selected-case review.
- Case actions were not discoverable. Added contextual “開始處理”, “確認改善”, and “重新開啟” actions; each opens the edit panel with the requested next status preselected. Saving still requires the private admin note, public-change consent, and database authorization.
- Marking a case resolved without an after photo was only enforced at the database layer. The editor now explains the missing evidence and keeps the save action unavailable; the repository and database checks remain in place.
- The Admin improvement-photo input received its required flag, matching the existing public report form requirement.
- The Demo reset capability existed in the About modal but had no reachable trigger. Added a Demo-only footer entry so testers can restore the eight seeded sample cases after local exercises.
- Magic Link redirect now uses the configured canonical public URL rather than the active localhost/Preview origin; the default is the Production site. Current Supabase Site URL and allow-listed redirects were inspected and already match the deployed domain plus local development URLs.

## Existing strengths preserved

OpenStreetMap remains the default provider. Public reports, manual/current-location selection, community updates, image compression and EXIF removal, safe public views, RLS, and Supabase-backed authorization were not redesigned or weakened. Demo remains local to the browser and writes in this QA pass were reset to the eight seeded samples.

## Remaining observations

- Admin owner Magic Link delivery had historical HTTP 200 evidence; this pass verified the callback target in code and the live Auth URL configuration, but did not consume a fresh owner link.
- Preview browser checks and physical-device GPS, camera, keyboard, screen-reader, and 200% zoom checks remain separate acceptance items.
- No live Supabase report, community update, photo upload, or admin status write was performed in this pass.
