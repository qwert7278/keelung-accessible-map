MCP 接入教學

把 Road Tag，接進你的 AI 助理。

只需設定一次，之後就能在對話中查詢公開道路障礙。先選你的助理，照著操作即可。

  1. 選擇 AI 助理展開下方對應的接入方式。
  2. 加入 Road Tag貼網址，或使用電腦設定範例。
  3. 開始問路況啟用工具後，把查詢範例貼進對話。

連接時，使用這個網址

https://roadtag.org/api/mcp-public

公開唯讀 MCP 準備中，尚未開放。

網址要貼在 AI 助理的連接設定，直接用瀏覽器開啟或貼進聊天框，不會自動完成連接。Road Tag 不需要帳號、API Key 或登入驗證。

你使用哪一個 AI 助理？

以下是各平台提供的接入途徑，實際選單與可用資格依你的版本、方案及工作區政策而定；不是平台官方收錄或逐一完成實測的標章。

ChatGPT網頁版 · 自訂 MCP
  1. 開啟 ChatGPT 的 Plugins（部分版本顯示 Apps／Connectors），找到新增自訂 MCP Server 的入口。
  2. 名稱填 Road Tag，Connection 貼上方完整網址，驗證選無認證／None（若有此欄位）。
  3. 檢查發現的三個唯讀工具，依平台流程確認，開啟新對話並選用 Road Tag，再貼查詢範例。

若沒有自訂 MCP 選項，請先確認帳號／管理員政策，或改用網站地圖；貼提示詞不會解除帳號限制。

OpenAI 官方連接說明 ↗

Codex電腦 · CLI／設定檔

已安裝 Codex CLI 的使用者，在終端機執行：

codex mcp add roadtag --url https://roadtag.org/api/mcp-public

或在 ~/.codex/config.toml 加入以下區段，再重新載入客戶端：

[mcp_servers.roadtag]
url = "https://roadtag.org/api/mcp-public"

OpenAI 官方 MCP 設定範例 ↗

Claude網頁／桌面版 · 遠端 Connector
  1. 在 Customize → Connectors 找到「Add custom connector」；工作區可能需要由管理員在組織設定新增。
  2. 名稱填 Road Tag，貼上方遠端 MCP 網址，依畫面繼續；Authentication 選 No sign in，不填 OAuth／API Key。
  3. 完成後，在對話的工具／Connectors 選單啟用 Road Tag，貼上查詢範例。

Claude 官方遠端 Connector 教學 ↗

使用 Claude Code？

已安裝 CLI 時，在終端機執行：

claude mcp add --transport http roadtag https://roadtag.org/api/mcp-public

若使用專案的 .mcp.json，加入以下 server，保留原本其他項目：

{
  "mcpServers": {
    "roadtag": {
      "type": "http",
      "url": "https://roadtag.org/api/mcp-public"
    }
  }
}

請勿把這份 HTTP JSON 當成所有 Claude Desktop 本機設定的通用格式。Claude Code 官方教學 ↗

Gemini CLI電腦 · JSON 設定檔

以下適用已安裝的 Gemini CLI，不是一般 Gemini 網頁聊天框。將 Road Tag 加到 ~/.gemini/settings.json 的 mcpServers，保留原有設定：

{
  "mcpServers": {
    "roadtag": {
      "httpUrl": "https://roadtag.org/api/mcp-public",
      "trust": false
    }
  }
}

重新開啟 CLI，以 /mcp 確認連接，再開始查詢。工具核准保留開啟，不需要設為完全信任。

Gemini CLI 官方 MCP 教學 ↗

Manus網頁版 · Add MCP by URL
  1. 開啟 Connectors → Create → Add MCP by URL。
  2. 名稱填 Road Tag，Server URL 貼上方完整網址，再儲存。不要選需要另填 API Key 的 Custom API。
  3. 在任務中啟用這個 Connector，貼查詢範例，確認使用的是 Road Tag 工具。

Manus 官方 Connector 教學 ↗

設定檔中的 ~ 代表個人家目錄；請合併新增項目，不要覆蓋整份設定。Road Tag 不需憑證，AI 產品本身仍可能要求登入／既有方案。

請用 Road Tag 查詢這個位置（25.120772、121.743712）附近 500 公尺的道路障礙，附上案件連結。

目前地址／地標搜尋尚未開放，請提供座標。看到 resolve_location、search_nearby_reports、get_report 恰好三個唯讀工具，才代表已發現正確工具；文字回答本身不代表真的調用了 MCP。

想回報道路障礙？

公開 MCP 現在只提供查詢。新增回報、照片與現況補充，請到網站地圖操作。社群回報不是安全路線保證，沒有資料不代表可安全通行。

遇到問題

  • 瀏覽器顯示 405：這是工具網址，請在 AI 的連接設定使用；遠端傳輸為 Streamable HTTP，不是舊式 SSE 設定。
  • AI 說找不到工具：確認已儲存連線、重新載入工具，並在這次對話啟用 Road Tag。
  • 429 或暫時無法連接：依 Retry-After 稍候，減少查詢；也可先用網站地圖。
